# Mile to Km Converter

Um simples conversor de **Milhas para Quilômetros** feito em Python com Tkinter.

## 🚀 Funcionalidades
- Entrada de valor em milhas.
- Conversão automática para quilômetros ao clicar no botão.
- Resultado exibido diretamente na interface gráfica.
- Tratamento de erros para entradas inválidas.

## 🖼️ Interface
A interface foi construída com o módulo **Tkinter**, contendo:
- Um campo de entrada (`Entry`) para digitar as milhas.
- Labels (`Label`) para exibir texto explicativo e resultado.
- Um botão (`Button`) para realizar a conversão.

## 📦 Requisitos
- Python 3.x (testado em 3.10+)
- Tkinter (vem instalado por padrão no Python)

## ▶️ Como executar
Clone este repositório e rode o script:

```bash
git clone https://github.com/seu-usuario/mile-to-km-converter.git
cd mile-to-km-converter
python main.py
```

## 📖 Exemplo de uso
1. Digite um valor em milhas no campo de entrada.
2. Clique em **Calculate**.
3. Veja o resultado em quilômetros aparecer na tela.

## 📌 Observações
- O programa está configurado para limitar o resultado a **três casas decimais**.
- Caso o usuário insira um valor inválido, o texto `Error` será exibido.
